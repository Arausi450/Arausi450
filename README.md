### LUMEN PON Optical Assurance

[Repository](https://github.com/Arausi450/lumen-pon-assurance) · [Live dashboard](https://arausi450.github.io/lumen-pon-assurance/)

A browser dashboard for a French passive optical access network (GPON and XGS-PON), covering 12 OLTs and about 11,440 ONTs across 4 regions. It moves from fleet health and the PON topology down to a live alarm feed and an upstream-delay prediction view. Device readings are simulated, while the alarm rules are the real ones.

### Real-Time Observability for a 5G PON Testbed

*IMT Atlantique engineering phase project, Feb 2026*

A real-time Grafana dashboard for the department's 5G PON testbed, where 16 ONUs share one upstream link, built on an InfluxDB backend queried with Flux. My part was the dashboard and checking the data's integrity against the testbed's master experiment log, with 3 supervisors guiding the project. The dashboard ran on the department's testbed, so it has no public link.
