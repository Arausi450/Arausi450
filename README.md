## Projects

**[LUMEN PON Optical Assurance](https://github.com/Arausi450/lumen-pon-assurance)** · [live dashboard](https://arausi450.github.io/lumen-pon-assurance/)

A browser dashboard for a French passive optical network (GPON and XGS-PON) with 12 OLTs and about 11,440 ONTs. It goes from fleet health down to live alarms and an upstream-delay prediction view. The device readings are simulated, while the alarm rules are the real ones.

**Real-time monitoring for a 5G PON testbed**

For my engineering phase project at IMT Atlantique, I built the Grafana dashboard that follows the department's 5G PON testbed live, with InfluxDB behind it, and I checked its data against the testbed's experiment log. It only ran on the department's testbed, so there is no public link.
